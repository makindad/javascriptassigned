Feature Comparison Operators Logical Operators
Purpose Used to compare two values and determine whether a relationship between them is true or false. Used to combine, modify, or evaluate one or more conditions in a JavaScript expression.
Common operators >, <, >=, <=, ==, ===, !=, !== &&, ||, !
Basic example 10 > 5 returns true because 10 is greater than 5. 10 > 5 && 20 > 10 returns true because both conditions are true.
Result Comparison expressions usually return either true or false. Logical expressions often return true or false when working with Boolean conditions, although JavaScript can also return the actual operand value.
Greater than 10 > 5 returns true. The > operator checks whether the left value is greater than the right value. Logical operators do not directly check whether one value is greater than another.
Less than 5 < 10 returns true. The < operator checks whether the left value is smaller than the right value. Logical operators can combine a less-than comparison with another condition, such as age < 18 || age > 65.
Greater than or equal to age >= 18 returns true when age is either 18 or greater than 18. Can combine it with another condition, such as age >= 18 && hasID === true.
Less than or equal to score <= 100 checks whether the score is 100 or lower. Can combine it with another comparison, such as score >= 0 && score <= 100.
Strict equality 10 === 10 returns true, while 10 === "10" returns false because the data types are different. Logical operators do not directly test equality, but equality expressions are commonly used inside logical expressions.
Loose equality 10 == "10" returns true because JavaScript converts the types before comparing them. Logical operators can combine loose equality conditions, although strict equality is generally preferred.
Strict inequality 10 !== "10" returns true because a number and a string are different types. Can be combined with other conditions, such as status !== "blocked" && age >= 18.
Logical AND && Comparison operators do not perform logical AND operations. condition1 && condition2 returns a truthy result only when both conditions are truthy. Example: age >= 18 && hasID === true.
Logical OR || Comparison operators do not perform logical OR operations. condition1 || condition2 succeeds when at least one condition is truthy. Example: hasCard || hasCash.
Logical NOT ! Comparison operators normally compare one value with another value. ! reverses the Boolean meaning of a condition. For example, !true becomes false and !false becomes true.
